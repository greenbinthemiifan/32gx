# 32gx Controller Mappings

Because Sega 32X games utilized both standard 3-button and 6-button Sega control pads, **32gx** supports multiple Nintendo Wii input devices to accommodate different game requirements.

---

## 1. GameCube Controller
The GameCube controller is a favorite for Wii homebrew due to its ergonomic layout and tactile buttons.

| GameCube Button | Sega 32X / Genesis Function |
| :--- | :--- |
| **Control Stick / D-Pad** | D-Pad (Movement) |
| **A Button** | B Button |
| **B Button** | A Button |
| **X Button** | C Button |
| **Y Button** | X Button |
| **Z Button** | Y Button |
| **L / R Triggers** | Z Button / Extra Trigger |
| **Start / Pause** | Start |

---

## 2. Wii Classic Controller / Classic Controller Pro
The Classic Controller provides a layout very similar to traditional SNES/PlayStation gamepads.

| Classic Controller Button | Sega 32X / Genesis Function |
| :--- | :--- |
| **Left Stick / D-Pad** | D-Pad (Movement) |
| **A Button** | B Button |
| **B Button** | A Button |
| **X Button** | C Button |
| **Y Button** | X Button |
| **L Button** | Y Button |
| **R Button** | Z Button |
| **Plus (+) Button** | Start |
| **Minus (-) Button** | Mode (Switch 3/6 button mode) |

---

## 3. Wii Remote (Horizontal / Sideways)
For simpler 3-button games when playing with just the Wii Remote held sideways:

| Wii Remote Button | Sega 32X / Genesis Function |
| :--- | :--- |
| **D-Pad** | D-Pad (Movement) |
| **2 Button** | B Button |
| **1 Button** | A Button |
| **A Button** | C Button |
| **Plus (+) Button** | Start |
| **HOME Button** | Exit to Emulator Menu / Homebrew Channel |
